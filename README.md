# 12402080601007_DAA_miniproject
Personal Expense Analyzer and Budget Assistant
1. Introduction
The Personal Expense Analyzer and Budget Assistant is a simple Python-based application developed to help users manage their daily expenses and control their spending. It allows users to record expenses, view their spending details, search expenses by category, sort expenses according to their amounts, and compare total expenses with a fixed budget.

The main purpose of this project is to make expense management easy while demonstrating important concepts of Design and Analysis of Algorithms (DAA), especially Linear Search and Merge Sort.
2. Objectives of the Project
- To record and display daily expenses.
- To search for expenses belonging to a particular category.
- To arrange expenses from lowest to highest amount.
- To calculate total spending and remaining budget.
- To understand the practical application of searching and sorting algorithms.
3. Technologies Used
- Programming language: Python
- Data structure: List
- Searching algorithm: Linear Search
- Sorting algorithm: Merge Sort
- Interface: Menu-driven, text-based interface
The program does not require any external library or database. Expenses are stored temporarily in a Python list while the program is running.
